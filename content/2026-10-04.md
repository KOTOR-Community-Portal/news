# Rough Patch

This update is all about the KotOR Patch Manager, an exciting new tool which has made possible all sorts of cool changes to the game's programming. There are patches to run the game in borderless windowed mode, increase the level cap in KOTOR 1, make the console visible in KOTOR 2, and back-port KOTOR 2 features like the "(empty)" label for empty containers, just to name a few.

KPM is still being beta tested and we can't properly integrate it into the Mod Builds nor provide official support yet, but we also don't want to block anyone from trying it out in the meantime. So, with a lot of help from J, one of the contributors, I've come up with a short list of adjustments to follow if you want to use the Mod Builds alongside the KotOR Patch Manager.

I must stress, though, that this is a rough set of guidelines and not official Mod Build instructions. Because development of KPM is ongoing and we haven't properly tested it with the Mod Builds yet, we cannot provide our usual level of support. You might be on your own with any issues that arise. Please keep this in mind if you do decide to try it out.

## Both Games

- Make sure to start off with your game's original executable or the editable executable from Deadly Stream. If you have already patched your executable, such as for widescreen or memory, it will not be usable with KPM.
- Do not use the 4GB Patcher linked in the Mod Builds. Instead, use the 4GB Memory Patch with KPM.
- Do not blindly enable all patches without reading about what they do as some patches conflict with each other and might not be applicable to you. We won't be vetting and recommending any specific patches before the next major version of the Mod Builds.
- KPM has patches for common issues like being unable to move after combat and grass not rendering correctly. It's worth trying these as you may be able to forgo a lot of the usual troubleshooting steps.

## KOTOR 1

- For the Galaxy Map Fix, ignore the installation instructions for widescreen and install the base mod only.
- Do not use UniWS for widescreen. Instead, use J's Scaled Kotor with KPM.
- Do not install HR Menus or HD UI Menu Pack as these are covered by Scaled Kotor.
- Using the Movie Patch with KPM fixes playback issues, so you no longer need to match the movies to your screen resolution for stability. You may still install Cutscenes Rescaled or Remastered Cutscenes if you would like to use their upscaled videos, however.
- The rest of the widescreen support mods are up to your personal preference. Use any of them if you prefer their changes over the base game/Scaled Kotor.

## KOTOR 2

- If you are using the Aspyr patch, do not use the 3C-FD Patcher, Water Restoration, and Stutter Fix linked in the Mod Builds. Instead, use the equivalent patches with KPM (i.e. the ones which say they fix something for the Aspyr patch).
- For Party Swap, there is an alternate option which is more consistent with the native user interface. Do not install the PartySwap Item add-on and instead, use the Full Party Select patch with KPM.
